---
title: Keyboard shortcuts
description: "Every default Jelly shortcut for tabs, panes, sessions, the explorer, the viewer and settings, all rebindable."
order: 1
---

All of these can be rebound in Settings → Keybinds or under `[keybinds]`. See [Keybinds](/docs/customize/keybinds/).

## Tabs

| Action | Keys |
|---|---|
| New tab | <kbd>⌘T</kbd> |
| Close pane (the tab, if it is the last pane) | <kbd>⌘W</kbd> |
| Close tab | <kbd>⌘⌥W</kbd> |
| Next / previous tab | <kbd>⌘⇧]</kbd> / <kbd>⌘⇧[</kbd> |
| Move tab left / right | <kbd>⌘⇧←</kbd> / <kbd>⌘⇧→</kbd> |
| Go to tab 1–9 | <kbd>⌘1</kbd> … <kbd>⌘9</kbd> |

## Panes

| Action | Keys |
|---|---|
| Split right | <kbd>⌘D</kbd> |
| Split down | <kbd>⌘⇧D</kbd> |
| Focus pane | <kbd>⌘⌥</kbd> + arrows |
| Zoom pane | <kbd>⌘⇧↩</kbd> |
| Equalize panes | <kbd>⌘⌃=</kbd> |

## Sessions and sidebar

| Action | Keys |
|---|---|
| New session | <kbd>⌘⇧N</kbd> |
| Next / previous session | <kbd>⌘⌃]</kbd> / <kbd>⌘⌃[</kbd> |
| Go to session 1–9 | <kbd>⌘⌃1</kbd> … <kbd>⌘⌃9</kbd> |
| Toggle sidebar | <kbd>⌘0</kbd> |

## Explorer and viewer

| Action | Keys |
|---|---|
| Toggle explorer | <kbd>⌘E</kbd> |
| Preview Markdown (selected file, or the directory's README) | <kbd>⌘⇧M</kbd> |
| Import a TOML file | <kbd>⌘⇧I</kbd> |

Keys inside the explorer, including type-to-filter, are listed in [Search files](/docs/explore/search-files/).

## General

| Action | Keys |
|---|---|
| Find in scrollback | <kbd>⌘F</kbd> |
| Settings | <kbd>⌘,</kbd> |
| Reload config | <kbd>⌘⇧,</kbd> |
