## 1. Make a session

Press <kbd>⌘⇧N</kbd> to create a session, for example *Work*. Every session keeps its own tabs and splits, so you can switch context in one click and everything you had open comes with you. Switch with <kbd>⌘⌃1</kbd> to <kbd>⌘⌃9</kbd>.

## 2. Save a project

Drag a folder from Finder onto the **Projects** list in the sidebar. Click it any time to open a new tab in that folder.

## 3. Split the tab

- <kbd>⌘D</kbd> splits right, <kbd>⌘⇧D</kbd> splits down.
- <kbd>⌘⌥</kbd> with an arrow key moves focus between panes.
- <kbd>⌘⇧↩</kbd> zooms the focused pane to fill the tab. Press it again to go back.

## 4. Open the explorer

Press <kbd>⌘E</kbd>. A file tree for the focused pane's directory opens on the right. `cd` somewhere else and it follows.

> **Try this.** With the explorer focused, just start typing a file name. The tree filters as you type. <kbd>Esc</kbd> clears the filter, and <kbd>Esc</kbd> again returns to the terminal. More in [Search files](/docs/explore/search-files/).

## 5. Read a file

Select a file in the explorer and press <kbd>↩</kbd>. Markdown is rendered, code is syntax highlighted, and the view reloads when the file changes. <kbd>Esc</kbd> closes it. See [File viewer](/docs/explore/file-viewer/).

## 6. Make it yours

Press <kbd>⌘,</kbd> to open Settings and choose a theme and font. Everything you change is written to `jelly.toml`.
