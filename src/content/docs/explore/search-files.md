The explorer has no search field, and it does not need one. **Click into it and start typing.**

## Type to filter

Every letter, number or punctuation character you type is added to a filter. The tree narrows to entries whose names contain what you typed, ignoring case. The filter shows in the explorer header as a small accent pill.

- <kbd>⌫</kbd> deletes the last character.
- <kbd>Esc</kbd> clears the filter. Press <kbd>Esc</kbd> again to return focus to the terminal.
- The first match is selected as you type, so <kbd>↩</kbd> opens it straight away.

> **Try this.** Open the explorer, type `read`, and press <kbd>↩</kbd>. You are now reading `README.md` without touching the mouse.

The filter matches the folders you have already expanded, so open a folder with <kbd>→</kbd> first if the file is inside it.

## Every key

| Keys | What it does |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> | Move the selection. |
| <kbd>→</kbd> | Open the selected folder. |
| <kbd>←</kbd> | Close the selected folder. |
| <kbd>↩</kbd> or <kbd>Space</kbd> | Open a file in the viewer, or toggle a folder. |
| <kbd>⌘↑</kbd> | Go to the enclosing folder. |
| <kbd>⌘↓</kbd> | Make the selected folder the root, or preview the selected file. |
| letters, numbers, punctuation | Filter by name. |
| <kbd>⌫</kbd> | Delete the last filter character. |
| <kbd>Esc</kbd> | Clear the filter, then return to the terminal. |

Press <kbd>⌘E</kbd> to close the explorer altogether.
